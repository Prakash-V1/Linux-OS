## How to use this repository

1. Open one file in `posts/`.
2. Try its commands in a suitable Killercoda Linux lab.
3. Check the output and note any differences in your environment.
4. Edit the draft to reflect what you actually learned.
5. Copy the approved text to LinkedIn when you choose to publish.

Practice platform: https://killercoda.com/

## Keeping your repository safe

GitHub repositories can be public or private. **If you want the content to remain private, create a private repository** and check repository visibility before pushing. A private repository is not a substitute for keeping secrets out of files.

Do not commit passwords, private keys, access tokens, or other credentials. Remove sensitive hostnames, IP addresses, personal data, and confidential logs from notes and screenshots.

These Markdown files are drafts. No LinkedIn post has been published or scheduled.

Some commands need systemd, internet access, or elevated privileges and may not work in every container. Use a suitable practice lab and avoid destructive commands on real systems.
